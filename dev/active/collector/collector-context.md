## 핵심 의사결정 (대화에서 확정된 것들, 코드에 그대로 반영)

- **사이트 스코프 최종**: 사람인, 커리어리, 원티드 3곳 모두 크롤링 기반으로 진행. 사람인은 공식 오픈 API(oapi.saramin.co.kr)도 있어서 신청은 해뒀지만 승인이 오래 걸려 지금은 크롤러로 우선 진행. 원티드는 공식 API가 사업자등록번호 필수라 개인은 신청 불가 → 크롤링으로 결정. 단, 원티드 상세 페이지에 "무단전재 또는 재배포, 재가공 및 **크롤링**할 수 없으며"라는 문구가 명시적으로 있음을 확인시켰고, 사용자가 이 회색지대를 감수하고 진행하기로 확정함(비상업적 개인 구직 목적, 재배포 없음이 근거). 잡코리아·인크루트는 robots.txt 전체 차단으로 보류. 로켓펀치는 형사처벌 경고+로그인 게이트로 영구 제외. 잡코리아·인크루트는 robots.txt 전체 차단(`User-agent: * / Disallow: /`)이라 제외, 나중에 재검토. **로켓펀치는 완전 제외** — robots.txt는 일반 크롤링을 허용하는 듯 보였지만, 실제 페이지에 "크롤링 등으로 동의 없이 수집 시 개인정보 보호법에 따라 형사처벌될 수 있다"는 명시적 경고가 있고 비로그인 상태에서는 공고 목록 자체가 안 보임(로그인 게이트). 재검토 대상도 아니고 자동화 스코프에서 영구 제외.
- **연결 방식**: 원티드는 절대 크롤링하지 않음 — 공식 OpenAPI(openapi.wanted.jobs)만 사용. 신청 후 키 발급까지 최대 3영업일.
- **중복 제거**: URL만 단독 키로 쓰지 않음. 사람인 등에서 같은 공고가 재노출되며 URL 파라미터가 바뀌는 사례가 있어 회사명+직무명+게시일 조합을 보조 키로 병행.
- **연차 판별**: 신입/1~3년/3~5년/5년+/경력/확인필요 — 다중 선택. 숫자가 명확하면 해당 구간 전부 체크(예: "2~10년"이면 1~3년+3~5년+5년+ 모두), 숫자 없이 "경력자"류면 경력+확인필요.
- **직무 판별은 키워드 매칭이 아니라 JD 전체를 읽고 판단**해야 함(A-2 확정 사항). 포함: 그로스·CRM·퍼포먼스 마케터, 사업개발/기획, 데이터분석가(데이터 엔지니어 제외), PM/PO. 제외: 인플루언서/SNS 마케터, CS 위주 마케팅, 데이터 엔지니어/개발자, 영업·행동 위주 분석직.
- **그룹(지원후보/참고용) 배정은 자동화하지 않음.** 연차 조건이 맞아도 최종 판단(전체적인 느낌, 마감 여부 등)은 사람 몫 — 실제 손 작업 예시에서 이 원칙이 재확인됨(연차 맞아도 참고용으로만 넣은 사례 다수).
- **통합채용(대규모 채용) 공고 처리**: 사람인 등에서 "홈페이지 지원"으로 여러 직무를 한 번에 모집하는 공고는, 태그 목록에 포함 카테고리가 하나라도 있으면 "확인필요"로 노션에 링크만 남기고, 하나도 없으면 완전히 제외. (실제 사례: (주)아이샵케어 — 사람인 통합채용 공고 안에 있던 "Data Analyst" 개별 포지션이 자체 채용사이트에 별도로 존재했음)
- **마감일 관리**: 마감일이 명확한 공고는 날짜 저장 → 매 실행마다 오늘 날짜와 비교해 자동으로 "마감됨" 체크. "상시채용"/"채용 시 마감"처럼 고정일 없는 건 방법 2(주기적 재방문)로만 확인 가능, 이번 1차 구현 범위 밖.
- **알림 전략**: 전체 실패는 GitHub Actions 기본 이메일로 충분. 부분 실패/이상 신호(수집 0건 등)는 별도 알림 채널 없이 노션 페이지에 상태 메모로만 남김. Slack 등 추가 알림은 나중에.
- **크롤링 시 이용약관/robots.txt 조사는 Claude Code가 먼저 하고, 실제 진행 여부(리스크 감수)만 사용자가 최종 판단.**

## 기술적으로 확인된 사항 (구현 중 발견)
- 사람인: 헤드리스 브라우저(Playwright)는 봇으로 감지돼 응답이 막힘. 반대로 단순 `requests`는 정상 동작. 검색 결과 링크는 매번 트래킹 파라미터가 달라 rec_idx만 뽑아 URL을 정규화해야 같은 공고를 같은 URL로 인식함.
- 커리어리: `requests`로 정상 동작. `/sitemap/job/0.xml`에 전체 공고 URL이 있음. 단, lastmod 날짜는 사이트 전체 재색인 시점에 일괄로 찍혀 있어 "최근 N일" 필터로 신뢰할 수 없음 — 신규 여부는 사이트맵 lastmod가 아니라 storage.py의 URL 기준 조회로 판단.
- 로켓펀치: **완전 제외.** 비로그인 상태에서 공고 목록이 안 보이고(로그인 게이트), 페이지에 "크롤링 등으로 동의 없이 수집 시 개인정보 보호법에 따라 형사처벌될 수 있음"이라는 명시적 경고문이 있음. robots.txt의 `search=yes` content-signal보다 이 경고가 우선한다고 판단.
